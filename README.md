# Guia Casa da Azóia

Guia local interativo para os hóspedes da Casa da Azóia (Azóia, Sintra). Projeto de marca Huse Innovation.

- Site: https://guia.casadaazoia.pt (GitHub Pages)
- `index.html` — a app inteira
- `data/conditions.json` — previsão de mar e vento, atualizada todos os dias
- `img/` — fotografias (créditos dentro da app e em `credits.json`)
- Fonte The Future: não incluída no repositório até confirmar a licença de uso web.
